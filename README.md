# 台股與美股含息回測工具 v1.1

本版更新：

- 最早開始日期固定為 2015/01/01。
- 若開始日期早於 2015/01/01：
  - 日期欄位顯示紅框
  - 顯示錯誤提示
  - 「開始回測」按鈕不可按
- 台股選取後直接顯示在輸入框，例如：
  `3088 艾訊`
  不再顯示「已選：3088.TWO 艾訊」的第二行。
- 股票搜尋只保留：
  - 台股上市 / 上櫃
  - 美國交易所股票 / ETF
  不再出現香港、日本、共同基金等結果。
- Worker 升級 v1.1：
  - 新增 `/batch-chart`
  - 0050、00631L、SPY、加權指數與 USD/TWD 由 Worker 依序批次取得
  - 單一完整區間優先查詢；失敗才分段
  - Yahoo query1/query2 重試與退避
  - 個別資料失敗不會讓其他基準一起中斷

## 更新順序

1. 先重新部署 `cloudflare-worker.js`
2. `/health` 確認 `"version":"v1.1"`
3. 再用新版 `index.html` 覆蓋 GitHub Pages 根目錄檔案
