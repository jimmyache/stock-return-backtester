# 台股與美股含息回測工具 v0.8

## 本版更新

- 修正長區間回測偶發 `Failed to fetch`
  - 先正常抓整段資料
  - 若失敗，自動切成 3 年一段重新取得
  - 每段具重試與逾時控制
  - 成功後自動合併股價、股息與拆股資料
- `^TWII` 僅在內部作為 Yahoo 代號，畫面統一顯示「加權指數」
- 頁尾改為：
  `資料來源：Yahoo Finance。比較基準預設包含 0050、00631L、SPY 與加權指數。`
- 其他 v0.7 功能維持不變

## 更新方式

只需以新版 `index.html` 覆蓋 GitHub Repository 根目錄的原檔。
Cloudflare Worker 不需重新部署。
