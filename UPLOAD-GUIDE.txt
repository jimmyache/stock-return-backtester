更新順序

A. Cloudflare Worker
1. Workers & Pages → 目前的 Worker → Edit code
2. 刪除舊程式
3. 貼上 cloudflare-worker.js
4. Deploy
5. /health 應看到：
   {"ok":true,"provider":"Yahoo Finance","apiKeyRequired":false}

B. GitHub Pages
1. 上傳新版 index.html
2. 覆蓋根目錄 index.html
3. Commit
