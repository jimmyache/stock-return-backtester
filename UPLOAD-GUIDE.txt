最簡單上線步驟

1. 解壓縮 ZIP。
2. GitHub → stock-return-backtester → Add file → Upload files。
3. 把 index.html、README.md、cloudflare-worker.js 上傳到 Repository 根目錄。
4. 用新版 index.html 覆蓋舊版。
5. Settings → Pages。
6. Source = Deploy from a branch。
7. Branch = main。
8. Folder = / (root)。
9. Save。
10. 開啟：
   https://jimmyache.github.io/stock-return-backtester/
